# הגדרת ההדפסה במחשב הדלפק

מסמך למי שמריץ את ההתקנה **על מחשב הדלפק עצמו** (כולל סשן קלוד קוד שנפתח שם).
במחשב המשרד אין את המדפסת התרמית ולכן אי אפשר לבצע כלום מהצעדים האלה מרחוק.

## הבעיה

דפדפן לא מדפיס לבד. `window.print()` פותח חלונית "הדפסה" ומחכה שאדם ילחץ בה —
זו הגנה מכוונת של הדפדפן, ואין API שמבטל אותה מתוך הדף. בדלפק זה אומר חלונית
אחרי כל מכירה.

מסלול WebUSB (הדפסה ישירה ב-ESC/POS, שגם פותחת את המגירה באותה פקודה) נבדק
ונפסל: הדרייבר `usbprint.sys` של ווינדוס מחזיק את המדפסת, והדפדפן מקבל
`Access denied`. אי אפשר לשחרר אותו בלי לנתק את המדפסת מתוכנת הקופה השנייה
שמשתמשת בה, ולכן ההדפסה עוברת דרך ווינדוס.

## הפתרון

הדגל `--kiosk-printing` מבטל את החלונית: כל הדפסה יוצאת ישירות למדפסת ברירת
המחדל. המסוף חייב להיפתח מדפדפן שהופעל עם הדגל הזה — קיצור רגיל לא יעבוד.
`tools/kiosk-print.bat` עושה בדיוק את זה (מעדיף Edge, נופל ל-Chrome).

## הצעדים

1. **קיצור בשולחן העבודה** — להעתיק את `tools/kiosk-print.bat` לשולחן העבודה,
   ולפתוח את המסוף רק ממנו. שווה לתת לו שם ברור כמו „מסוף כניסה”.

2. **מדפסת ברירת מחדל** — המדפסת התרמית. אפשר מ-PowerShell:

   ```powershell
   Get-CimInstance Win32_Printer | Select-Object Name, Default
   (Get-CimInstance Win32_Printer -Filter "Name='<שם המדפסת>'").SetDefaultPrinter()
   ```

3. **לכבות ניהול אוטומטי של ברירת המחדל** — אחרת ווינדוס מחליף את ברירת המחדל
   למדפסת האחרונה שהשתמשו בה, וההדפסה הבאה תצא למקום אחר:

   ```powershell
   Set-ItemProperty 'HKCU:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Windows' `
     -Name LegacyDefaultPrinterMode -Value 1
   ```

4. **העדפות הדרייבר** — גודל נייר 80 מ"מ, ופתיחת מגירה בסוף ההדפסה. חלק
   מהדרייברים חושפים את זה דרך `Set-PrintConfiguration`, וחלק רק בחלון ההגדרות
   של היצרן. **פתיחת המגירה נעשית רק כאן** — במסלול ההדפסה דרך ווינדוס אין לנו
   דרך לשלוח את פקודת הפתיחה בעצמנו.

5. **מצב ההדפסה במסך** — בראש מסוף הכניסה יש מתג מצב הדפסה. ברירת המחדל היא
   „ווינדוס”, וזה הנכון כאן. „ישירה” היא מסלול ה-WebUSB שנפסל.

## איך יודעים שזה עבד

מכירת בדיקה אמיתית בדלפק: הקבלה יוצאת מהמדפסת **בלי שנפתחה שום חלונית**,
והמגירה נפתחת. אם נפתחה חלונית — המסוף לא נפתח מהקיצור. אם יצאה לאן שלא צריך —
ברירת המחדל התחלפה (צעד 3).
