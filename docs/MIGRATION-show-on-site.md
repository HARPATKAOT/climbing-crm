# מיגרציה — עמודת `show_on_site` בטבלת `activities`

**נדרש לפני שהאתר הציבורי יציג פעילויות.**

האתר השיווקי מציג רק פעילויות שסומנו במפורש «להציג באתר הציבורי». הסימון הזה
נפרד מ-`registration_enabled` בכוונה: לאירוע פרטי (יום הולדת) יש קישור הרשמה
שהמזמין מפיץ בעצמו, והוא אסור בפרסום באתר.

בלי העמודה הזו במסד, הסימון **נמחק בשקט** בדרך לשמירה (`server/supa.js` ממפה
רשימת עמודות מפורשת), והאתר יישאר ריק מפעילויות גם אחרי סימון.

## מה להריץ

ב-Supabase → SQL Editor:

```sql
ALTER TABLE activities
  ADD COLUMN IF NOT EXISTS show_on_site boolean NOT NULL DEFAULT false;
```

`DEFAULT false` מכוון: כל הפעילויות הקיימות — כולל אירועים פרטיים — נשארות
לא מפורסמות, והבעלים מסמן ידנית את מה שהוא רוצה לפרסם.

## אימות

1. במערכת: פתחו פעילות → «הפעלת דף הרשמה ציבורי» → סמנו «להציג באתר הציבורי» → שמרו.
2. רעננו את הפעילות וודאו שהסימון נשמר.
3. `GET /api/public/activities` צריך להחזיר אותה.

אם אחרי המיגרציה הסימון עדיין לא נשמר — בדקו שהעמודה קיימת בשם המדויק
`show_on_site` ושהיא לא נחסמת על ידי RLS.
